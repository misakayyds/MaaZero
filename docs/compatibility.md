# 兼容性与验收状态

当前没有获得正式兼容承诺的设备组合。所有测试均为本地测试或交叉编译，未连接手机。

| 项目 | 当前证据 | 不能据此推断 |
| --- | --- | --- |
| ARM64 Linux 后台 | Go 静态交叉编译 | Android 真机启动通过 |
| Magisk / KernelSU / APatch | 探测 fixture、模块布局及固定入口检查 | 三种管理器均能正常安装和打开 WebUI |
| 原 WebUI 复用 | 本地真实页面 + 模拟后台浏览器测试 | 实际 chroot / MAA 调度已接通 |
| rootfs 安全解包 | 合成归档拒绝/允许测试 | 真实 Debian 归档可直接安装和冷启动 |
| 更新事务 | 下载、哈希、切换失败及恢复的本地测试 | 断电、强制退出和手机重启均已验收 |

只读探测中的 ARM64、Android API 30+、Root 权限等是必要技术条件，不是支持清单。正式发布必须记录设备型号、Android 版本、Root 管理器及版本、包哈希和每项验收证据。

禁止为通过检测关闭 SELinux、修改系统分区、重启现有生产手机或覆盖旧 Debian。上述行为不属于本地开发授权。
