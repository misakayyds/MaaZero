# MAA 手机模块使用说明（本地预览版）

> 当前可以构建预览模块 ZIP，但还不能一键安装和运行 MAA。预览后台默认仅提供恢复入口；安装、更新和回退执行未开放。没有已验收设备清单，请勿在日常挂机手机上刷入。以下“正式版流程”是待完成的目标，不是当前能力承诺。

## 当前预览能看什么

现有 WebUI 中只增加“关于与模块设置”，原首页、周计划、基建和培养页面保留。该区域显示后台版本、环境状态、更新状态和帮助；未配置发布源或未接通运行驱动时会解释原因，不能点击安装来绕过。界面浏览器测试使用本地模拟后台，不代表手机已装好环境。

预览包自带本文，无需联网阅读。模块没有附带 Debian、游戏账号、通知凭证或维护者个人计划，也不会自动接管现有 `/data/local/debian` 环境。预览包的构建办法见维护者说明；现在不提供刷入教程，避免把尚未验收的步骤误当作低门槛正式安装。

## 使用前需要什么

- 一台已 Root、列入项目兼容清单的 ARM64 Android 手机。
- 已安装并能正常登录的明日方舟客户端；游戏登录由用户在游戏内完成。
- 可用网络及安装向导要求的剩余空间。具体下载量由所选版本清单计算，不写死估计值。

不要求自行安装 Debian、配置 SSH、使用终端或填写 ADB 地址。本项目不提供 Root/解锁 bootloader 教程，不承诺支持所有 Root 手机。

## 正式版首次安装流程（尚未开放）

1. 从项目正式发布页下载模块 ZIP，不使用仓库的源码 ZIP。
2. 在受支持的 Root 管理器中安装模块，阅读兼容性结果，按提示重启。
3. 从模块入口打开管理页面。不同管理器入口可能是 WebUI 或操作按钮；不要求额外安装总控 APK。
4. 查看检测结果、下载量与空间需求，点击安装环境。中断时重试，不重复刷模块。
5. 选择游戏客户端，先做连接检测；需要打开游戏时，页面应另外明确提示。
6. 安装成功后进入原有 MAA WebUI，手动执行第一次任务，确认结果后再开启定时计划。

Telegram、培养目标和复杂基建排班均为可选配置，首次安装不强迫填写。项目中不预装维护者的配置、凭证或账号状态。

## 日常使用

继续使用原有首页、周计划、基建和培养页面。培养首版是目标规划和刷材料，自动合成/实际升级不包含在这次模块分发范围内。不要把“材料齐备”当作游戏内已经升级。

新增的“关于与模块设置”集中放置版本、环境状态、更新、回退、帮助和诊断；不用在另一套控制台重新设置计划。

## 正式版更新目标（尚未开放）

目标是默认稳定通道，自动检查、用户确认后安装。测试通道和空闲自动安装需要主动开启。当前仅有手动检查入口，尚无周期自动检查、通道切换或后台自动安装。正式页面将说明更新内容、下载量、是否需要重启和是否允许回退。

任务运行时不切换组件。失败时区分“下载未完成”“未切换版本”“已恢复原版本”和“需要人工处理”，不一律显示可以继续运行。用户数据与程序分开保存；不通过重新安装来清空培养进度或计划。

## 常见问题

| 现象 | 处理方向 |
| --- | --- |
| 检测不兼容 | 停止安装，查看具体缺项；不要通过修改系统服务或关闭 SELinux 强行绕过 |
| 下载失败 | 检查网络后重试；已有正常版本不应被删除 |
| 空间不足 | 停止安装并保留数据；预览版尚无页面清理下载缓存功能 |
| 游戏任务失败 | 保留任务日志；预览版尚无诊断包导出，不直接重置系统或清空配置 |
| 更新失败 | 查看是否已恢复原版本；若恢复也失败，使用模块救援说明，先停止任务 |
| 管理页面无法打开 | 确认模块是否启用、是否已完成所需重启；按当前 Root 管理器的模块救援说明处理 |

## 卸载和隐私

模块卸载默认停止服务并保留用户数据。彻底清理是独立操作，需要明确显示目录和不可恢复影响；不能夹在普通卸载或更新里。

诊断包必须脱敏。提交问题前预览内容，不上传账号凭证、通知凭证、私钥或完整私人配置。首发前必须验证这项保护。

## 正式教程发布门槛

- 用真实模块截图替换草案说明，注明管理器和模块版本。
- 从空环境完成安装、手动运行、计划保存、升级、失败恢复、卸载保留数据验收。
- 离线帮助随模块/救援页面打包，不依赖外部站点才能查看。
- 维护者另有构建、签名、测试通道推广到稳定通道的发布操作说明。
