# MaaZero 手机模块使用说明

欢迎使用 **MaaZero**——零电脑依赖、零命令行折腾、零系统接管的手机端 MAA 独立沙箱模块。本文档已内置于模块包中，无网状态下也可随时查阅。

## 一、使用前准备

1. **兼容的 Root 设备**：64 位 ARM（`arm64-v8a`）Android 11–16 手机或平板，已安装 **KernelSU**（推荐）、**APatch** 或 **Magisk**。
2. **游戏客户端**：已安装《明日方舟》官服（`com.hypergryph.arknights`）或 B 服（`com.hypergryph.arknights.bilibili`），并已在游戏内手动登录过一次账号。
3. **存储空间**：建议 `/data` 分区预留至少 **5 GB** 可用空间，用于存放独立 Debian 运行环境、MaaCore 核心库与游戏更新包缓存。

无需电脑、无需安装 Termux 或额外总控 APK、无需手动开启无线调试输入配对码。

---

## 二、首次安装与初始化步骤

1. **刷入模块并重启**
   - 从官方发布页下载正式模块包 `MaaZero-v0.1.0.zip`（请勿刷入 GitHub 源码包）。
   - 在 KernelSU / APatch / Magisk 的「模块」页选择本地安装，完成后重启手机。
2. **打开管理界面并部署沙箱**
   - **KernelSU / APatch 用户**：在模块卡片直接点击 **WebUI** 按钮。
   - **Magisk 用户**：在模块卡片点击 **操作（Action）** 按钮，系统默认浏览器会自动打开 `http://127.0.0.1:8088`。
   - 进入「关于与模块设置」区域，点击 **检查更新**，确认签名校验通过后点击 **安装 / 应用更新**。后台会自动下载并原子部署 `debian-rootfs` 与 `maa-phone-project` 组件，并拉起本地服务。
3. **初始化 MAA 核心与资源**
   - 沙箱启动后进入主控制台，先确认顶部或配置中的客户端类型（官服 / B 服）。
   - 点击 **更新 MAA 资源**：首次运行时系统会自动执行 `maa install --batch` 安装 `MaaCore` 核心与资源包，并同步基建技能门槛索引。
4. **验证运行与开启定时计划**
   - 建议先手动点击一次开始运行或唤醒检测，确认本机回环 ADB 连接与游戏启动正常后，再在「周计划」中启用自动排班。

---

## 三、日常功能说明

- **首页总控**：一键启停日常任务、查看实时运行日志、检查并在线升级官服《明日方舟》客户端 APK、手动触发 `MaaCore` 与活动关卡资源热更新。
- **周计划**：按星期配置关卡序列、理智药到期自动服用阈值与定时唤醒计划（由沙箱内 `cron` 自动调度）。
- **基建轮换**：支持三班倒轮换排班，自动对照干员基建技能门槛索引给出配置校验。
- **干员盒与培养规划**：支持扫描游戏内干员练度与仓库库存，计算目标干员精英化/专精材料缺口并规划刷图目标（注：仅作规划与刷取材料，不会在游戏内自动消耗材料升级干员）。
- **关于与模块设置**：集中展示守护进程与组件版本、通道状态、在线检查更新与**离线回滚**入口。

---

## 四、在线更新与故障回滚

- **安全空闲切换**：点击应用更新后，下载在后台流式完成；若当前有正在执行的 MAA 挂机任务，`maa-managerd` 会等待任务结束释放任务锁后再原子切换版本，绝不中途打断挂机。
- **自动回退与离线回滚**：新版本切换后会自动执行健康检查，若未通过将自动切回旧版本；即使遇到网络中断或远端源不可达，你也可以随时在「关于与模块设置」中点击 **回滚上一版本** 恢复本地上一版可用环境。

## 五、常见问题排查

| 现象 | 排查与处理建议 |
| :--- | :--- |
| 点击模块入口后网页打不开 | 确认模块处于启用状态且刷入后已重启；等待开机后约 10–20 秒让 `service.sh` 拉起 `127.0.0.1:8088` |
| 环境或资源下载中断 | 检查手机网络（访问 GitHub Releases 是否顺畅）后再次点击重试，无需重刷模块 ZIP |
| 首次运行提示缺少 `libMaaCore.so` | 点击面板上的「更新 MAA 资源」，等待首次 `MaaCore` 自动下载安装完成即可 |
| 游戏无法被拉起或停在桌面 | 检查客户端包名选择是否正确（官服 / B 服），确认手机未冻结《明日方舟》后台启动权限 |
| 更新失败提示保留当前版本 | 先查看事务状态提示；如新版本异常，直接点击「回滚上一版本」，**切勿盲目删除数据目录** |

## 六、卸载与数据隐私

- **卸载默认保留数据**：在 Root 管理器中卸载模块仅会停止 `maa-managerd`、关闭沙箱内进程并干净卸载挂载点，`/data/local/maa-platform` 下的所有计划、培养记录与运行环境均会完整保留。
- **彻底清理方法**：如需完全释放约数 GB 的沙箱与资源空间，请先在 Root 管理器中卸载模块并**重启手机**，再使用 Root 文件管理器删除 `/data/local/maa-platform` 目录。
- **隐私承诺**：所有监听端口均严格限制在 `127.0.0.1` 回环网络；反馈问题前请检查日志，避免附带个人通知 Token（如 Telegram Bot Token）。
